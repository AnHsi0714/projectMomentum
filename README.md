# Momentum｜律動計畫

一個每天打開就知道「現在該做什麼」的個人時間表。

把一週的作息排成固定的時間表，畫面最上方顯示目前的時段、還剩多久，以及接下來要做什麼。旁邊可以勾選每天的習慣、寫下當天的進度，週末再回答幾個固定問題做回顧。

是照作者的作息做的：上課、深度工作、英文、閱讀、運動，以及就寢時間。時間表與習慣都寫在設定檔裡，換成個人習慣就能使用。

## 畫面

- **今天**：現在的時段、進度尺與整天的時間表。任務按開始才開始、按結束才結束，時間表只當參考，晚開始或沒做完都不用改；吃飯、洗澡這類浮動事項按開始時會暫停正在做的任務，之後可以繼續。習慣是否達標依實際紀錄自動判斷。計畫真的變了才調整當天的時間表：任務直接在時間條上拖，可以暫時重疊，衝突都解開才能確認，也能插入開會這類時間確定的任務，身體疲累可以開恢復模式，取消當天剩下的運動。今日達標與每日筆記也在這一頁。
- **本週**：每個習慣這週做了幾天，以及每天各類時段的時間。
- **回顧**：每週的固定問題，可以匯出與匯入備份。
- **名詞**：時段名稱的意思，以及時間不夠時先保住什麼、先放掉什麼。

## 開始使用

需要 Node.js 20.19 以上（或 22.12 以上）。

```bash
npm install
npm run dev
```

瀏覽器會自動開啟。請用 `npm run dev` 執行，紀錄才會存進專案的 `data/` 資料夾。

## 改成你自己的

- **時間表**：`src/config/schedule.ts`，每個時段寫成 `[開始, 結束, 名稱, 類型]`。
- **習慣與每週目標、回顧問題**：`src/config/habits.ts`。
- **名詞說明**：`src/config/terms.ts`。

## 資料與隱私

紀錄只存在你的電腦：專案裡的 `data/momentum.json`，瀏覽器也會留一份暫存。`data/` 已經列入 `.gitignore`，不會被提交到 Git。要備份請用「回顧」頁的匯出。
