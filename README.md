# Momentum｜週間自律

個人用的週間時間表與習慣追蹤。打開看「現在該做什麼」，並記錄每天的習慣、筆記與每週回顧。

## 功能

- **今天**：顯示目前時段、剩餘時間與下一個時段；時間表高亮現在，已過的時段變淡。可切換查看本週其他天。
- **模式**：每天可選正常、調整、恢復。恢復模式會把運動時段標示為取消。
- **習慣追蹤**：每天打勾，本週頁顯示「完成次數 / 每週目標」。
- **每日筆記**：記錄深度工作的產出、進度與下一步。
- **本週**：七天時間表總覽與習慣進度。
- **回顧**：每週固定問題，自動儲存；可匯出／匯入備份。

## 快速開始

需要 Node.js 18 以上。

```bash
npm install
npm run dev
```

會自動開啟瀏覽器。**日常請用 `npm run dev`**，這樣紀錄才會寫入資料夾。

| 指令                | 說明                           |
| ------------------- | ------------------------------ |
| `npm run dev`       | 開發伺服器，含存檔功能         |
| `npm run build`     | 型別檢查並建置到 `dist/`       |
| `npm run preview`   | 預覽建置結果（同樣含存檔功能） |
| `npm run typecheck` | 只做型別檢查                   |

## 資料存放

- 主檔：`data/momentum.json`，由開發伺服器的 `/api/data` 讀寫。
- 瀏覽器 localStorage 會同步存一份暫存；第一次啟動時若檔案是空的，會把瀏覽器裡的舊資料搬進檔案。
- 若伺服器沒開，頁面右上角會顯示「僅瀏覽器暫存」。
- 「回顧」頁有匯出／匯入 JSON 按鈕可另外備份。
- 建議用 Git 管理此專案，`data/momentum.json` 就會有版本紀錄。

資料結構（`src/types.ts` 的 `AppData`）：

```json
{
  "checks": { "2026-11-13": { "english": true } },
  "modes": { "2026-11-13": "normal" },
  "notes": { "2026-11-13": "..." },
  "reviews": { "2026-11-09": { "0": "..." } }
}
```

`reviews` 的 key 是該週週一的日期。

```
    habits.ts            習慣目標、三種模式、回顧問題
  lib/

```

## 如何修改

- **改時間表**：編輯 `src/config/schedule.ts`。每個時段格式為 `[開始, 結束, 內容, 類型]`，星期 `0` 是週日。
- **改習慣或每週目標**：編輯 `src/config/habits.ts` 的 `HABITS`。`detail` 欄位預留給之後決定的教材、運動菜單等細項。
- **改回顧問題**：編輯 `REVIEW_QUESTIONS`。
- **改顏色**：編輯 `src/styles/_tokens.scss`。

## 規則摘要

- 每天 23:00 就寢，不延後睡眠來補進度。
- 深度工作區塊以 60–90 分鐘為主，一次只做一個主要任務，結束時記錄進度與下一步。
- 休息前先決定要休息多久。
- 不補償：今天沒完成的，明天不要做兩倍。
- 同一時間只維持一個主要自主專案。
