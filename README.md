# Momentum｜律動計畫

一個每天打開就知道「現在該做什麼」的個人時間表。

把一週的作息排成固定的時間表，畫面最上方顯示目前的時段、還剩多久，以及接下來要做什麼。  
做完的任務自動算進每天的習慣，旁邊可以寫下當天的進度，週末再回答幾個固定問題做回顧。

是照作者的作息做的：上課、深度工作、英文、閱讀、運動，以及就寢時間。  
時間表與習慣都寫在設定檔裡，換成個人習慣就能使用。

## 畫面

- **今天**：現在的時段、進度尺與整天的時間表。  
  任務按開始、結束記下實際時間，計畫只是一開始的安排，晚開始或沒做完都不用改。  
  做到一半可以暫停、切回前一個任務，之後再繼續；結束了想再做也能接著做。  
  時間表以實際為準：做過的照實際時間排，休息與現在的位置也跟著時間走。  
  計畫變動或忘了按開始、結束，都在「調整時間表」裡拖動修改，過去的日子也能修正；身體疲累可以開恢復模式。  
  今日達標與每日筆記也在這一頁，細節見 [docs/rules.md](docs/rules.md)。
- **本週**：每個習慣這週做了幾天，以及每天各類時段的時間。
- **回顧**：每週的固定問題，可以匯出與匯入備份。
- **名詞**：時段名稱的意思，以及時間不夠時先保住什麼、先放掉什麼。

## 開始使用

需要 Node.js 20.19 以上（或 22.12 以上）。

```bash
npm install
npm run dev
```

瀏覽器會自動開啟。  
請用 `npm run dev` 執行，紀錄才會存進專案的 `data/` 資料夾。

## 個人化時間表

- **時間表**：`src/config/schedule.ts`，每個時段寫成 `[開始, 結束, 名稱, 類型]`。
- **習慣與每週目標、回顧問題**：`src/config/habits.ts`。
- **名詞說明**：`src/config/terms.ts`。

## 資料與隱私

紀錄只存在自己的電腦：專案裡的 `data/momentum.json`，瀏覽器也會留一份暫存。  
`data/` 已經列入 `.gitignore`，不會被提交到 Git。  
要備份請用「回顧」頁的匯出。
