## 程式：資料檔變大時

目前所有紀錄都存在 `data/momentum.json`，估計一天 3 到 5 KB，一年 1 到 2 MB，讀取與存檔都還很快。  
最先碰到的限制是瀏覽器 localStorage 的備份，上限約 5 MB。

檔案超過 2 到 3 MB 時：

- [ ] 先改成存檔不縮排，可以小三到四成
- [ ] 再不夠就按年封存：去年的實際紀錄與時間表搬到 `momentum-年份.json`，主檔只留今年

新增畫面都要符合 WCAG AA，先跑 `npm run check`。
